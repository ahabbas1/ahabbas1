# Abigail Connectors - Working Rules
Project: webhook connectors for Abigail's webinar funnel (GHL, Flodesk, WebinarJam). One Vercel project, one handler per connector. No Zapier.
Rules:
- Read the official API docs before writing code. Never guess an API from memory.
- If you need information that is not in this folder or my message, ask me. Never guess names (tags, segments, field IDs).
- Never put a key or secret in code, in any file in this folder, or in chat. Keys go in Vercel environment variables only.
- Dry run first, then one real test, then automate. Delete test contacts afterwards.
- Walk me through every step, including where to click. I am not technical.
- Keep code simple and readable.
